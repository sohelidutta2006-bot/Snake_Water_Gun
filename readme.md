# 🐍 Snake Water Gun Game

A modern and interactive **Snake Water Gun** game built using **Python, Django, HTML, and CSS**. Challenge the computer, keep track of your score, and be the first to reach **5 points** to win the match.

---

## 🚀 Live Features

- 🎮 Play Snake, Water, or Gun against the computer
- 🤖 Random computer moves
- 🏆 First player to reach **5 points** wins the match
- 📊 Live scoreboard
- 🤝 Draw counter
- 🔄 Play Again functionality
- ❌ Quit Game with confirmation dialog
- 👋 Professional Goodbye page
- ✨ Modern Glassmorphism UI
- 📱 Responsive design

---

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3
- **Templating:** Django Templates
- **Session Management:** Django Sessions

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/sohelidutta2006-bot/Snake_Water_Gun.git
```

### Navigate to the project

```bash
cd Snake_Water_Gun
```

### Create a virtual environment

```bash
python -m venv venv
```

### Activate the virtual environment

#### Windows

```bash
venv\Scripts\activate
```

#### macOS/Linux

```bash
source venv/bin/activate
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the server

```bash
python manage.py runserver
```

Open your browser and visit:

```
http://127.0.0.1:8000/
```

## 🎯 Game Rules

- 🐍 Snake drinks Water
- 💧 Water drowns Gun
- 🔫 Gun shoots Snake
- 🤝 Same choice results in a Draw
- 🏆 First player to score **5 points** wins the match
